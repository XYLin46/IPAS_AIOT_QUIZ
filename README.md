# IPAS 物聯網應用工程師題庫｜AIOT 線上練習

<p><a href="https://xylin46.github.io/IPAS_AIOT_QUIZ/" style="font-size: 2.4em; font-weight: bold;">▶ 直接進入練習網頁</a></p>

IPAS AIOT Quiz 是一個以繁體中文提供的物聯網應用工程師認證線上題庫，
適合準備 IPAS 物聯網應用工程師檢定、複習 AIOT 基礎概念，以及進行考前模擬測驗。

## 網站特色

- 依學年度與單元整理物聯網應用工程師題目
- 歷屆年度測驗可選擇單次作答 5、10、20 或完整 50 題
- 隨機題庫測驗可選擇單次作答 5、10、20 或 50 題，並優先抽選未做題目
- U1 題庫依「AIoT 應用工程師（初級）學習指引－科目 1」九個單元分類，可選章節集中刷題
- U2 題庫依工研院「物聯網系統與應用」課程分為系統元件與架構、故障判斷與排除、資安與隱私、平台設計四類
- 交卷後顯示逐題詳解、正確答案與作答標記
- 支援線上作答、即時查看答案與錯題複習
- 以瀏覽器 `localStorage` 保存個人練習進度，不需註冊帳號
- 適合手機與桌面瀏覽器使用

## SEO 關鍵字與內容定位

網站主要關鍵字為：`IPAS`、`物聯網應用工程師`、`AIOT`、`物聯網題庫`、
`物聯網檢定`、`歷屆試題`、`線上測驗`。

頁面標題使用「IPAS 物聯網應用工程師題庫｜AIOT 線上練習」，讓搜尋引擎與使用者
能快速了解網站主題。後續發布內容時，建議以自然且有幫助的方式加入單元名稱、
題型與學習情境，避免重複堆疊關鍵字。

## 使用方式

直接開啟網站即可開始練習。題目資料位於 `questions_json/`，由
`questions_json/manifest.json` 管理可選的學年度與單元。

U1 章節清單位於 `questions_json/u1-chapters.json`，章節模式只會載入
`*-U1.json`；U2 題目不會出現在 U1 章節刷題中。各題的 `explanation`
欄位會在交卷後顯示，方便理解錯誤原因。
